# Тестовое задание ТОЛЬКООПТ — расчёт рекомендованной цены

Python 3.10+, только стандартная библиотека.

```bash
python starter.py              # пример: price=4728.00, decision=APPLY
python -m unittest -v          # тесты (pytest тоже подойдёт: python -m pytest -v)
```

## Что исправлено в `recommend_price`

- Ожидание источника ограничено `asyncio.wait_for(..., timeout_s)`; тайм-аут, исключение и `status != "success"` → текущая цена и `HOLD`.
- Фильтр: учитываются предложения с `delivery_days` не `None` и ≤ 6 (раньше `None` ронял сравнение), собственный магазин `MYSHOP` исключается без учёта регистра.
- Нет подходящих предложений → текущая цена и `HOLD` (раньше `min([])` падал с `ValueError`).
- Расчёт в `Decimal` вместо `float`, округление вниз до копейки (`ROUND_FLOOR`) вместо банковского `round`.
- Учитывается `min_price`: рекомендация = max(конкурент − 1,5%, min_price).
- Изменение > 30% в любую сторону → `REVIEW`, ровно 30% → `APPLY`; сравнение точное, в `Decimal`.
- Возвращается `Decimal` и понятная причина в `reason`.
